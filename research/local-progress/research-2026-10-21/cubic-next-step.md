# Paused cubic-surface sketch, 21 October 2026

Research was redirected to the ES7 cloud project before a new theorem was established. This file records a promising **unproved** direction, not a completed result.

The natural structural target is to improve the existing either-side fixed-formula cubic bound from p^(15/8) to p^(7/4) by extending the row-monodromy argument from Kummer palette covers to general descended finite Galois palette covers. This would be a second-moment argument on the actual surface, rather than another per-character triangle inequality.

For a palette witness cover Z -> P1_a, let N be the normal subgroup generated by finite nonzero inertia, and a=tau*w^n its Kummer quotient. For fixed nonzero potential u, the collision quartic has four roots a_i and paired colors b_i=(v/u)a_i. After restricting potentials to one n-th-power coset and adjoining r^n=v/u, take quotient coordinates w_ai^n=a_i/tau and w_bi=r*w_ai. At v=-u one color root has a simple pole. This gives the old independent Kummer coordinates. One would next adjoin the eight residual N-covers, associated to the a_i and b_i.

A plausible generic-row argument is that their finite nonzero branch loci are independent: fixing one color to any fixed nonzero branch value determines v algebraically, and coincidence with another fixed color branch value forces u into a finite exceptional set. If all residual inertia survives, normal generation should give a full bounded-degree geometric row group, normally generated by its nonzero finite inertia. The branch values should vary nontrivially with u, so any fixed row has only O(1) other rows sharing a branch value. Chebotarev and the old Gram-matrix calculation would then give operator norm O(p^(3/4)) and the desired support bound.

The unresolved tasks are substantial: prove generic-row connectedness uniformly; check collisions between branch loci on different quartic sheets; identify the full group or sufficient normal generation; control relative constants and arithmetic Frobenius cosets; prove all exceptional u form a uniformly bounded set; and ensure branch loci have no constant nonzero v component. No resulting theorem is claimed.

A fallback additive-Fourier observation is elementary but was not developed because it repeats the excluded per-character strategy. For the kernel exp_p(-(r*a^2*b+s*a*b^2)(1+t(a+b))), every pair of distinct rows has a degree-at-most-three Weil correlation except bounded harmless degeneracies; thus its operator norm is O(p^(3/4)) for (r,s) != (0,0). This would cover additive-Wiener supports such as intervals, with arbitrary palettes, but is a different restricted hypothesis and does not resolve arbitrary sets.

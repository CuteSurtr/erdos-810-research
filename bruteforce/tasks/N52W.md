## Closure check and report

At the end, run:

```
python3 ../common/closecheck.py 52 13 <base.cnf> --roots <your roots> \
  --logs ../../PUSH2/N52/logs/leaves_n52*.jsonl logs/leaves_new.jsonl
```

Save its output to `S<i>/logs/closecheck.txt`. The script recomputes each leaf's CNF hash and accepts only
`s VERIFIED UNSAT`. It derives each split from `tree.py`'s rule, not from the logs, so a branch that never ran is
OPEN. Your shard is done when every one of your roots is CLOSED.

`S<i>/REPORT.md` must give:
- placement (`uname -a`, `nproc`, `free -g`);
- roots closed and open;
- leaf counts, solver seconds, max leaf time and LRAT volume;
- any UNKNOWN re-splits;
- the closecheck output;
- for any open root, the open branches and an estimate of the remaining cost.
